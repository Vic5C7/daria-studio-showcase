# AGENTS.md

## 适用范围

本文件适用于 `wiki/` 以及其下的产品文档、规划文档和原型区域。

`wiki/` 是产品规划区，不是正式业务代码区。

## 文档规则

- 文档文件名和目录名保持英文。
- 除 `AGENTS.md` 外，Markdown 文档内容使用英文优先、中文紧随的双语对照。
- `AGENTS.md` 内容保持纯中文，必要技术词如 `GitHub Pages`、`Docker`、`API` 可以保留英文。
- 用户故事应保留稳定编号，例如 `US-001`。
- 已被替代的需求可以保留在文档中，但必须明确标注为已被替代。

## Wiki 维护边界

- `user-stories/` 记录用户故事和需求拆分。
- `acceptance-criteria/` 记录验收标准和可测试预期。
- `testing/` 记录测试计划和测试用例。
- `decisions/` 记录重要产品、架构和工作流决策。
- `architecture/` 记录数据模型、内容模型和 API 草案。
- `product/` 记录产品范围、用户旅程和后台工作流。
- `prototype/` 存放原型产物，具体规则见 `wiki/prototype/AGENTS.md`。
- 真实客户网站、工作人员后台、后端 API、CMS、数据库、认证和部署实现属于私有仓库 `daria-studio-platform`。

## 工作边界

- 除非用户明确要求，或用户提供了外部路径，否则在 `wiki/` 内的任务默认不要向上修改仓库根目录或私有真实代码仓库。
- 普通文档整理不应顺手修改原型源码。
- 产品文档可以描述未来正式系统，但不应在 `wiki/` 中实现正式业务代码。
