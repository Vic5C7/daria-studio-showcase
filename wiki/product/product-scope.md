# Product Scope

This document will define the product scope for the DARIA STUDIO website.

Initial direction:

- Customer-facing website for viewing studio information, work samples, and packages.
- Staff admin interface for managing editable content.
- Backend API and database-backed content system.
- Draft and publish workflow for staff content changes.

Out of scope until explicitly added:

- Customer accounts
- Online payment
- Full booking/order management
- Production database implementation before the schema is designed
