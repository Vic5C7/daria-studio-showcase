# User Journey
# 用户旅程

This document describes the main customer and staff journeys.
本文档描述主要客户旅程和工作人员旅程。

Initial journeys:
初始旅程：

- Customer explores work samples and pricing.
- 客户浏览作品样片和价格套餐。
- Customer prepares a package enquiry.
- 客户准备套餐咨询信息。
- Staff edits service, package, add-on, and gallery content.
- 工作人员编辑服务、套餐、加购项和作品展示内容。
- Staff reviews and publishes content changes.
- 工作人员审核并发布内容变更。

Detailed journey maps should link back to user stories and acceptance criteria.
更详细的旅程地图应关联到用户故事和验收标准。
