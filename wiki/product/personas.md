# Personas
# 用户画像

This document describes the main user groups for the DARIA STUDIO website.
本文档描述 DARIA STUDIO 网站的主要用户群体。

Initial personas:
初始用户画像：

- Photography customer.
- 摄影客户。
- Studio staff member.
- 工作室工作人员。
- Studio owner or administrator.
- 工作室负责人或管理员。

The personas should be expanded as user stories and admin workflows become clearer.
随着用户故事和后台工作流变得更清晰，这些用户画像应继续扩展。
