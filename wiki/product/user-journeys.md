# User Journeys
# 用户旅程

## Visitor journey
## 访客旅程

1. Open the gallery and understand the studio positioning.
   打开作品页并了解工作室定位。
2. Switch between Chinese and English.
   在中文和英文之间切换。
3. Review packages and filter available services.
   查看套餐并筛选当前可用服务。
4. Decide whether to sign in or contact the studio.
   决定登录或联系工作室。

## Client journey
## 客户旅程

1. Register or log in.
   注册或登录。
2. Review package choices and add notes about requirements.
   查看套餐选择并添加需求备注。
3. Continue to the confirmed booking flow when it is available.
   在预约流程上线后继续完成预约。
4. Return later to view the personal album and download delivered images.
   之后返回查看个人相册并下载交付图片。

## Admin journey
## 管理员旅程

1. Sign in with an admin account.
   使用管理员账号登录。
2. Edit gallery content, ordering, visibility, bilingual copy, and pricing configuration.
   编辑作品内容、排序、可见性、双语文案和价格配置。
3. Open the customer list and select a client album.
   打开客户列表并选择客户相册。
4. Review or update album content and return to the public management view.
   查看或更新相册内容并返回管理视图。

## Journey principles
## 旅程原则

- A visitor can understand the offer before creating an account.
  访客在创建账号前可以理解服务内容。
- Availability and pricing states are explicit rather than hidden.
  可用性和价格状态必须明确展示，而不是隐含在界面中。
- Client and admin capabilities are separated by role.
  客户和管理员能力按角色隔离。
- A later production implementation must replace demo persistence with server-side persistence.
  后续正式实现必须用服务端持久化替代演示用本地持久化。
