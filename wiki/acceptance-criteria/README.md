# Acceptance Criteria
# 验收标准

Store acceptance criteria for user stories and product flows here.
这里存放用户故事和产品流程对应的验收标准。

Use clear, testable statements.
请使用清晰、可测试的表达。

A good default format is:
推荐默认格式如下：

```text
Given [context],
when [action],
then [expected result].

在 [上下文] 下，
当 [用户动作] 时，
则 [预期结果]。
```

Acceptance criteria should be specific enough to guide implementation and QA.
验收标准应足够具体，能够指导实现和测试。
