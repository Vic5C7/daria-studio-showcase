# Data Model Draft
# 数据模型草案

This document will capture draft database entities and relationships.
本文档用于记录数据库实体和关系草案。

Current direction:
当前方向：

- Content should be editable by staff rather than hard-coded in the frontend.
- 内容应由工作人员编辑，而不是硬编码在前端。
- Public pages should read published content.
- 公开页面应读取已发布内容。
- Staff pages should be able to work with draft content.
- 工作人员页面应能够处理草稿内容。
- Bilingual display fields should be designed intentionally.
- 双语展示字段应被有意识地设计。

Initial entities to consider:
初步需要考虑的实体：

- Service area.
- 服务地区。
- Service type.
- 服务类型。
- School.
- 学校。
- Scene type.
- 场景类型。
- Package.
- 套餐。
- Add-on category.
- 加购类别。
- Add-on item.
- 加购项。
- Media asset.
- 媒体素材。
- Content version.
- 内容版本。
- Staff user.
- 工作人员用户。

This file is a draft only and should not be treated as the final schema.
本文件只是草案，不应被视为最终数据库结构。
