# Test Cases

Use this file to collect test cases before a formal test management tool exists.

## Test Case Template

```text
ID:
Title:
Related story:
Type: Manual | Frontend | Backend | Database | End-to-end
Preconditions:
Steps:
Expected result:
Status: Draft | Ready | Passed | Failed | Blocked
Notes:
```

## Initial Test Case Areas

- Customer gallery loads published images.
- Customer language switch preserves the selected language.
- Customer package selection calculates expected total.
- Staff login accepts valid credentials and rejects invalid credentials.
- Staff content edits are saved as draft.
- Draft content is not visible on the customer site before publishing.
- Published content appears on the customer site.
- Disabled or unavailable service types do not appear as selectable customer options.
- Media assets can be added, ordered, hidden, and published.
