# Prototype
# 原型

This folder stores prototype artifacts for the DARIA STUDIO website.
本文件夹存放 DARIA STUDIO 网站的原型产物。

The current runnable high-fidelity prototype is located at `high-fidelity/`.
当前可运行的高保真原型位于 `high-fidelity/`。

The prototype is used for demos, visual reference, interaction reference, and product discussion.
原型用于演示、视觉参考、交互参考和产品讨论。

The prototype should not be treated as the production architecture.
不要把原型当作正式架构。

GitHub Pages currently deploys the high-fidelity prototype.
GitHub Pages 当前部署的是高保真原型。
