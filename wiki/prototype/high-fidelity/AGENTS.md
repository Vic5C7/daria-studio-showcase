# AGENTS.md

## 适用范围

本文件适用于当前可运行的高保真原型工程。

该工程使用 React、TypeScript 和 Vite，用于客户展示、视觉验证和交互验证，不是未来正式前端。

## 工程规则

- 保持原型实现轻量，优先服务展示和需求确认。
- 不要加入真实登录、数据库、后台管理、支付或复杂预约流程。
- 不要把正式系统架构决策写死在原型里。
- 修改用户可见文案时，需要保留中文和英文内容。
- 修改图片、路由或资源路径时，需要保持 GitHub Pages 兼容。
- 不要提交 `node_modules/`、`dist/` 或其他生成产物。

## 验证规则

- 修改本目录中的源码、配置、样式或资源后，需要运行原型构建检查。
- 构建检查使用本目录内的 `npm run build`。
- 如果修改 Docker 相关文件，需要确认根目录 Docker 本地预览路径仍然指向本原型。
- 如果修改 Vite base path 或部署相关配置，需要确认 GitHub Pages 仍能正确加载资源。

## 工作边界

- 除非用户明确要求，或用户提供了外部路径，否则本目录任务默认不要向上修改 `wiki/prototype/`、`wiki/`、仓库根目录或 `repos/`。
- 如果原型变更需要同步文档，应在结果中说明建议同步的位置，而不是顺手扩大修改范围。
