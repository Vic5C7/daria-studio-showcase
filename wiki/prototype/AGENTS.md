# AGENTS.md

## 适用范围

本文件适用于 `wiki/prototype/` 以及其下的原型产物。

原型用于演示、视觉参考、交互参考和产品讨论，不是正式系统架构。

## 原型规则

- 原型可以做小修小补，例如文案、图片、布局或样式调整。
- 不要把原型扩展成真实系统。
- 不要在原型里实现真实登录、数据库、后台管理或复杂业务逻辑。
- 不要把原型代码直接迁移到 `repos/` 当作正式架构。
- 修改原型时需要考虑 GitHub Pages 和 Docker 本地预览。

## 高保真原型

- 当前可运行高保真原型位于 `wiki/prototype/high-fidelity/`。
- 修改该目录前，还需要阅读 `wiki/prototype/high-fidelity/AGENTS.md`。
- 高保真原型可以继续用于客户展示和需求确认。

## 工作边界

- 除非用户明确要求，或用户提供了外部路径，否则在 `wiki/prototype/` 内的任务默认不要向上修改 `wiki/` 其他文档、仓库根目录或 `repos/`。
- 如果原型变更影响产品规则，应单独说明是否需要同步更新用户故事、验收标准或决策记录。
