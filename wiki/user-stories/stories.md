# User Stories
# 用户故事

## Visitor stories
## 访客故事

| ID | Story | 故事 | Priority |
|---|---|---|---|
| US-001 | As a visitor, I want to browse selected work so that I can understand the studio style. | 作为访客，我希望浏览精选作品，以便了解工作室风格。 | Must |
| US-002 | As a visitor, I want to switch language so that I can read the experience comfortably. | 作为访客，我希望切换语言，以便舒适地阅读。 | Must |
| US-003 | As a visitor, I want to explore packages so that I can estimate whether the service fits my needs. | 作为访客，我希望浏览套餐，以便判断服务是否适合我的需求。 | Must |

## Client stories
## 客户故事

| ID | Story | 故事 | Priority |
|---|---|---|---|
| US-004 | As a client, I want to create an account so that my booking and album information has a stable identity. | 作为客户，我希望创建账户，以便预约和相册信息有稳定归属。 | Must |
| US-005 | As a client, I want to save requirements notes so that the studio can understand my request. | 作为客户，我希望保存需求备注，以便工作室理解我的需求。 | Must |
| US-006 | As a client, I want to access my album so that I can review delivered images. | 作为客户，我希望访问我的相册，以便查看交付图片。 | Must |
| US-007 | As a client, I want to download album images so that I can keep a local copy. | 作为客户，我希望下载相册图片，以便保存本地副本。 | Must |

## Admin stories
## 管理员故事

| ID | Story | 故事 | Priority |
|---|---|---|---|
| US-008 | As an admin, I want to manage gallery visibility and ordering so that the public page stays current. | 作为管理员，我希望管理作品可见性和排序，以便公开页面保持最新。 | Should |
| US-009 | As an admin, I want to manage pricing data so that package information can change without redeploying the frontend. | 作为管理员，我希望管理价格数据，以便修改套餐时不必重新部署前端。 | Must |
| US-010 | As an admin, I want to find a customer and open the correct album so that I can support delivery. | 作为管理员，我希望找到客户并打开正确相册，以便支持交付工作。 | Must |

## Story rules
## 故事规则

Each story must link to acceptance criteria before entering implementation. A story that depends on an unresolved pricing, permission, or booking rule remains in discovery.
每个故事进入开发前必须关联验收标准。依赖未解决价格、权限或预约规则的故事继续处于探索状态。
