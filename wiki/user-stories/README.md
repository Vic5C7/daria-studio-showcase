# User Stories

This folder stores user stories for the DARIA STUDIO website.

Start here:

- [Stories By Epic](stories-by-epic.md)

Story IDs use the `US-###` format so future acceptance criteria, test cases, and design
notes can reference the same requirement.

Status labels:

- `Active`: current product direction.
- `Prototype`: already represented in the high-fidelity prototype.
- `Next`: expected for the first real production build after architecture decisions.
- `Later`: useful but intentionally out of the first formal build.
- `Decision needed`: discussed requirement with an unresolved product decision.
- `Superseded`: recorded for traceability, but replaced by a later requirement.
