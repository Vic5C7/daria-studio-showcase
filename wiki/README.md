# Wiki
# Wiki 文档区

This folder stores product and planning documents for the DARIA STUDIO website.
本文件夹存放 DARIA STUDIO 网站的产品和规划文档。

It is intentionally separate from `repos/`, which is reserved for production code.
它有意与 `repos/` 分离，因为 `repos/` 预留给正式代码。

Main areas:
主要区域：

- `user-stories/`: user stories and story maps.
- `user-stories/`：用户故事和故事地图。
- `acceptance-criteria/`: acceptance criteria and testable expectations.
- `acceptance-criteria/`：验收标准和可测试预期。
- `prototype/`: prototype artifacts and prototype notes.
- `prototype/`：原型产物和原型说明。
- `product/`: scope, personas, and journeys.
- `product/`：产品范围、用户画像和用户旅程。
- `architecture/`: data model and API drafts.
- `architecture/`：数据模型和 API 草案。
- `testing/`: test strategy, test cases, and coverage notes.
- `testing/`：测试策略、测试用例和覆盖说明。
- `decisions/`: decision log entries.
- `decisions/`：决策记录。
