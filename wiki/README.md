# Wiki Guide
# Wiki 使用说明

This directory contains product documentation only. It is not the implementation repository.
本目录只存放产品文档，不是正式业务实现仓库。

## Documentation order
## 文档阅读顺序

1. Product scope and prototype baseline.
   产品范围与原型基线。
2. Functional requirements, user stories, and acceptance criteria.
   功能需求、用户故事与验收标准。
3. Technical boundary, domain model, and API draft.
   技术边界、领域模型与 API 草案。
4. Testing and agile delivery process.
   测试与敏捷交付流程。

## Maintenance rules
## 维护规则

- Update the relevant requirement and acceptance criterion when a confirmed behavior changes.
  已确认行为发生变化时，同时更新对应需求和验收标准。
- Record important product or technical choices in `decisions/`.
  重要产品或技术选择记录在 `decisions/`。
- Keep `wiki/prototype/` as the approved visual and interaction reference.
  保持 `wiki/prototype/` 作为已确认的视觉和交互参考。
- Do not put production application code in this public repository.
  不要在本公开仓库中编写正式应用代码。
