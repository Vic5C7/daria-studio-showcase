# 前端

This folder is reserved for the future production frontend.
本文件夹预留给未来正式前端。

The production frontend is expected to include the customer-facing website and the staff admin interface.
正式前端预计会包含客户可见网站和工作人员后台。

No production framework has been initialized here yet.
这里目前还没有初始化正式前端框架。

Before implementation starts, confirm the frontend framework, routing strategy, authentication boundary, and content API shape.
正式实现前，需要先确认前端框架、路由策略、认证边界和内容 API 形态。

Do not copy the high-fidelity prototype into this folder as production architecture.
不要把高保真原型直接复制到这里当作正式架构。
