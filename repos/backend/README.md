# Backend
# 后端

This folder is reserved for the future production backend.
本文件夹预留给未来正式后端。

The backend is expected to support APIs, authentication, database access, content editing, draft preview, and publishing.
后端预计会支持 API、认证、数据库访问、内容编辑、草稿预览和发布。

No production backend service has been initialized here yet.
这里目前还没有初始化正式后端服务。

Before implementation starts, confirm the backend framework, database schema, authentication model, deployment target, and API contract.
正式实现前，需要先确认后端框架、数据库结构、认证模型、部署目标和 API 契约。

FastAPI remains a likely backend direction, but the final choice should be made after the database and admin requirements are clearer.
FastAPI 仍然是一个较合适的后端方向，但最终选择应在数据库和后台需求更清楚后确定。
